# 🚀 VPN Configs — Топ-100 рабочих конфигов

Автоматически обновляемый список **100 лучших VPN-конфигов**, отобранных по реальной задержке (latency) из нескольких публичных источников. Проверка выполняется локально, поэтому в список попадают только те серверы, которые действительно работают из вашего региона.

---

## 📥 Готовая ссылка для подписки

https://raw.githubusercontent.com/BYAsurim/vpn-configs/refs/heads/main/best_100.txt

Добавьте эту ссылку как подписку в ваш VPN-клиент (v2rayNG, Hiddify, Streisand, v2rayN и др.):

**Как добавить:**
- **v2rayNG (Android):** Меню → Группы подписок → «+» → вставить ссылку → Обновить.
- **Hiddify (Android/iOS):** Настройки → Подписки → «+» → вставить ссылку → Обновить.
- **Streisand (iOS):** Настройки → Подписки → «+» → вставить ссылку.
- **v2rayN (Windows):** Серверы → Импорт из буфера обмена (или Импорт из файла).

---

## ⚙️ Как это работает

1. **Сбор:** Скрипт `check.bat` скачивает конфиги из 8 публичных подписок на GitHub.
2. **Дедупликация:** Удаляются дубликаты (одинаковые соединения).
3. **Тестирование:** Каждый конфиг проверяется на реальную задержку через HTTP-запрос.
4. **Сортировка:** Рабочие конфиги сортируются по скорости (быстрые → медленные).
5. **Отбор:** В `best_100.txt` попадают **первые 100** — самые быстрые и стабильные.
6. **Публикация:** Файл автоматически заливается в этот репозиторий.

## 🕒 Расписание обновлений

Скрипт запускается вручную и обновляет `best_100.txt`. Каждый запуск:

- Скачивает свежие конфиги из источников.
- Тестирует их из сети (это важно — блокировки зависят от региона).
- Заливает обновлённый топ-100 на GitHub.

---

## ⚠️ Важно

- Конфиги берутся из **публичных источников** и не являются приватными.
- Работоспособность может меняться со временем — именно поэтому список обновляется автоматически.
- Если конфиг перестал работать, просто обновите подписку в клиенте — скрипт уже заменит его на новый.
